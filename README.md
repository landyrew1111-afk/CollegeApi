
# Электронный дневник колледжа

Приложение для учёта успеваемости студентов: ASP.NET Core Web API + WPF-клиент.
Работает с существующей базой данных MS SQL Server, структура и данные БД не изменялись.

## Состав решения

| Проект | Назначение |
| --- | --- |
| `CollegeApi` | REST API (ASP.NET Core, EF Core, Swagger) |
| `WpfApp1` | Настольный клиент (WPF) |

## Запуск

1. Откройте `CollegeApi.slnx` в Visual Studio 2022+.
2. В качестве запускаемого проекта выберите `CollegeApi` и нажмите **F5**.
   API поднимется на `https://localhost:7264` (Swagger: `https://localhost:7264/swagger`).
3. Запустите `WpfApp1` (можно вторым проектом в том же профиле запуска).
   Клиент сам определяет адрес API: `https://localhost:7264/api`, при недоступности — `http://localhost:5097/api`.

Запуск из консоли:

```powershell
dotnet run --project CollegeApi/CollegeApi.csproj --launch-profile https
dotnet run --project WpfApp1/WpfApp1.csproj
```

## Демонстрационные аккаунты

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `admin123` |
| Преподаватель | `prep_ivanova` | `teacher123` |
| Преподаватель | `prep_petrov` | `teacher123` |
| Студент | `student1` … `student5` | `student123` |

Пароли хранятся в БД в открытом виде (учебный проект, без хеширования).

## Возможности по ролям

**Администратор**
- оценки: журнал текущих оценок — добавление, изменение, удаление, фильтры по группе/дисциплине, поиск;
- ведомость: итоговые оценки студентов с фильтрами и редактором;
- пользователи: создание, изменение, удаление (связанные студент/преподаватель и оценки обрабатываются автоматически). После создания строка подсвечивается и появляется подтверждение; пустой пароль заменяется на `12345`;
- справочники: группы, специальности, дисциплины, виды контроля и учебный план (специальность, дисциплина, преподаватель, семестр, часы, вид контроля);
- профиль: данные аккаунта и смена пароля.

**Преподаватель**
- видит только свои дисциплины (по нагрузке из учебного плана);
- выставляет и правит текущие и итоговые оценки;
- меняет свой пароль.

**Студент**
- раздел «Мои оценки»: текущие и итоговые оценки по всем дисциплинам;
- профиль: группа, зачётная книжка, средний балл;
- смена пароля.
